# KicqUWP

KicqUWP — это современный неофициальный ICQ-клиент для Windows 10 mobile (UWP), разработанный с использованием C#. Проект ориентирован на работу с протоколом OSCAR, поддержку фоновых задач (Control Channel Trigger) и современные стандарты Windows.

## 🚀 Основные возможности
* **Протокол OSCAR**: Реализация взаимодействия с сервером KICQ.
* **Фоновые уведомления**: Использование `ControlChannelTrigger` для получения сообщений при свернутом приложении.
* **Переподключение**: Встроенный сервис автоматического восстановления связи при потере сети.
* **Работа с контактами**: Синхронизация списка контактов и статусов в реальном времени.

## 🛠 Технологический стек
* **Язык**: C#
* **Платформа**: Universal Windows Platform (UWP)
* **Сеть**: `Windows.Networking.Sockets`
* **Синхронизация**: `ObservableCollection`, `Task`, `CancellationToken`

## 🏗 Как начать работу

### Требования
* Visual Studio 2017 (с установленной нагрузкой «Разработка приложений для универсальной платформы Windows»).
* Windows 10 версии 1511 или выше.

### Сборка
1. Клонируйте репозиторий: `git clone https://github.com/Inklime/kicquwp.git`
2. Откройте файл `kicquwp.sln` в Visual Studio.
3. Убедитесь, что выбрана архитектура `ARM`.
4. Нажмите `F5` для запуска проекта.

## 📂 Структура проекта
* `OscarProtocol.cs`: Основная логика работы с протоколом (парсинг FLAP/SNAC).
* `ReconnectService.cs`: Сервис мониторинга состояния сети и автоматического реконнекта.
* `CCT/`: Логика работы с фоновыми задачами и Push-уведомлениями.
* `ViewModels/`: Логика отображения данных (MVVM).

## 💡 Известные проблемы
* В текущей версии ведется работа над оптимизацией обработки событий при смене состояния сети.
* Ограниченная поддержка некоторых расширенных возможностей протокола ICQ.
